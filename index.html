DESARROLLO WEB

HTML,CSS Y Javascript:

diseñado por santiago

son los tres pilares fundamentales del desarrollo web que trabaja juntos para crear paginas web dinamicas e interactivas. HTML se encarga de la estructura y el contenido CSS del diseño y la presentacion y JAVASCRIPT de la interactividad y la funcionalidad.

Definiciones:

HTML(Hypertext Markup language):

Es el lenguaje de mercado que define la estructura y el contenido
de una pagina web. Utiliza etiquetas para delimitar diferentes
elementos, como parrafos, encabezados, imagenes,enlaces, etc.

CSS(Cascading Style Sheets):

Es un lenguaje de estilos que se utiliza para controlar la presentacion
de una pagina web. permite definir aspectos como los colores, fuente,
tamaños, margenes, etc, de los elementos de HTML.

Javascript(Program, languaje):

Es un lenguaje de de programacion que permite agregar funcionalidad
interactiva a una pagina web. Permite manipular elementos HTML.
responder a eventos del usurio realizar calculos etc.

Analogia de la web y una casa:

HTML

Estructura de la casa

Es como los cimientos, las paredes, techos y distribucion de las habitaciones
HTML define la estructura basica de una pagina web que elementos hay (titulo, parrafos, botones,
imagenes, etc), pero sin preocuparse por como se ven

CSS

Decoracion y estilos de la casa.

Es la pintura de las paredes, el tipo de piso los muebles, las cortinas el diseño de la cocina.

Css se encarga de como se ve la pagina: colores, fuentes, margenes, alineaciones, estilos responsivos.... lo visual.

JavaScript

Los sistemas eletricos y electronicos de la casa.

Es como los interruptoes que encienden luces, las puertas automaticas , el termostato inteligente.

JavaScript añade funcionalidad e interactividad haciendo que pasen cosas como respuestas como respuestas a un evento.
